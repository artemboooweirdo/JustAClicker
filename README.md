# JustAClicker
I am making a simple clicker with a few permanent upgrades
# How To Open
Open the game in https://artemboooweirdo.github.io/JustAClicker/ and click the button to play!
# Process of Creation
I am new to hackclub and I wanted to see what I could do using html, css and js. I made a clicker game because thats honestly where most people start in game development. Some of my inspiration came from Roblox upgrade trees such as EUT and Upgradex and I think that this project turned out to look really nice and I like how the final product is functional and (somewhat) aesthetic. This was an interesting week for me and I am looking forward to making more projects!
